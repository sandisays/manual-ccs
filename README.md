# Manual Digital CCS

Manual de certificação (SIGSIF, DCPOA, modelos de CSI, unidades e normas).

- `index.html`: o manual, com o conteúdo criptografado (AES-GCM). Abre só com a senha.
- `enc/`: prints, PDFs e a página de Newcastle, também criptografados com a mesma senha.

Nenhum arquivo deste repositório tem conteúdo em texto aberto. Para abrir, baixe a pasta inteira e abra o `index.html` num servidor web (ou publique no Cloudflare Pages / GitHub Pages).
